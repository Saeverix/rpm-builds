Saeverix RPM repository

RPMs for tools that Fedora does not package, or ships too old. Built and signed by GitHub Actions from Saeverix/rpm-builds.

Install on Fedora

sudo curl -o /etc/yum.repos.d/saeverix.repo \
  https://rpm./saeverix.repo
sudo rpm --import https://rpm./RPM-GPG-KEY-saeverix
sudo dnf install mangowm

Install on AlmaLinux 10

sudo curl -o /etc/yum.repos.d/saeverix.repo \
  https://rpm./saeverix-almalinux.repo
sudo rpm --import https://rpm./RPM-GPG-KEY-saeverix
sudo dnf install fish

Use in a Fedora Atomic / bootc image

RUN curl -o /etc/yum.repos.d/saeverix.repo \
      https://rpm./saeverix.repo && \
    rpm --import https://rpm./RPM-GPG-KEY-saeverix && \
    dnf -y install mangowm && \
    dnf clean all

The repo files set skip_if_unavailable=0 on purpose, so an unreachable repo fails the image build rather than quietly producing an image without these packages.

Signing

Every package is signed, and repomd.xml carries a detached signature, so the repo files enable both gpgcheck and repo_gpgcheck.

2BE1 5FF9 C232 EAC2 4237  DC91 2AC7 5B07 5AFD 843E

RPM-GPG-KEY-saeverix

The three newest builds of each package are kept, so a bad bump can be downgraded away. -debuginfo, -debugsource and source RPMs are not published — they are rebuildable from the tagged spec.
